## ① 전체 목적함수 J (평가에 사용, 판단 통합은 미구현)

```
J = c_t·T_total + c_p·N_pallet + c_h·N_intervene + c_u·N_unprocessed
```

| 항목 | 값 | 근거 |
|---|---|---|
| c_t | 1 / s | 기준 단위 |
| c_p (팔레트 1개 환산) | A 2000 / B 2000 / C 5000 / D 1000 s | ⚪ A는 🟡 팀 보상 비율 0.0005/s와 동일 |
| T_change (팔레트 교체) | A 60 / B 180 / C 120 / D 60 s | ⚪ |
| 놓기 / 버퍼 이동 / 재적재 1회 | 8 / 4~5 / 12 s | 🟡 `config/taehyeon/highlevel.yaml` |
| c_h, c_u | 미정 | 실험에서 개입·미처리가 0이라 아직 영향 없음 |

## ② 자리 평가 점수 (시제품 `lookahead.py`)

```
cost = Σ eff_i·f_i − φ(S; 0.75, 20, 2) − φ(L; 0.5, 8, 0.5)
φ(x; t, a_lo, a_hi) = a_lo·min(x, t) + a_hi·max(0, x − t)
S = 0.20 지지 + 0.25 맞물림 + 0.40 min(1, a_c / 0.3 g) + 0.15 옆면
```

| 항목 | 근거 |
|---|---|
| 0.3 g | 🟣 랩 전제 |
| S 기준 0.75, 기울기 20 / 2 | 🟢 0.6·0.9, 10·40 탈락 |
| S 내부 비중, L 기준·기울기, 효율 7개 가중치 (2, 2, 2, 1.5, 4, 1.5, 0.5) | 🟠 |

**T(로봇 작업시간) 누락**: 요약서 점수식의 T가 자리 점수에 없습니다. 이동 거리 기반 시간을 추가해야 합니다.

**요청과의 차이**
- 0.3 g가 하드 제약이 아니라 점수 항목입니다.
- 충격 항목이 μ = 0.4에서 포화되어 목표 0.2~0.4에 둔감합니다.
- 기둥 전체를 보지 않고 새 박스 하나만 봅니다.
