## 1. 계산 구조: 하나의 계획을 계속 갱신 (박스별 계산 아님)
```
[계획] = 목표 배치도 + 대기열 박스 각각의 할당(칸 / 버퍼 / 배치도 밖 자리) + 미입고 박스용 칸

● 박스가 컨베이어에 입고(라벨링): 계획에 추가, 기존 계획을 출발점으로 이어서 최적화
● 그 사이 계속: 계획 전체를 조금씩 개선
● 박스가 픽업존 진입: 그 박스는 계산 대상에서 제외(고정) → 계획의 행동 실행
                     → 실측 결과 반영 후 나머지 박스로 계속 최적화
```
- 대기열 박스들의 자리를 함께 정하므로, 버퍼를 이용한 박스 간 순서 조합을 계획 안에서 직접 찾습니다.
- 고정된 박스가 로봇 검증에 실패하면 계획의 다음 후보를 쓰고, 실측 위치가 계획과 다르면 즉시 갱신합니다.

## 2. 계획 단계
| 단계 | 내용 |
|---|---|
| L1 목표 배치도 | 현재 팔레트 + 남은 박스로 이상적 완성 배치를 계산 → SKU별 구역 지도. 대기열이 바뀔 때마다 갱신 |
| L2 후보 생성 | EMS/극점 + 코너점 + 이웃 밀착 보정 |
| L3 하드 제약 | 겹침·돌출·높이 · SKU별 허용 하중(누적) · 받침 · **충격 내성 ≥ 0.3 g (기둥 전체)** · 가반하중·도달성 |
| L4 빠른 점수 | 아래 3장 |
| L5 시나리오 평가 | 대기열(실측) + 상류(무게 샘플링) + 미입고(순서 샘플링). 행동: 놓기 / 버퍼 꺼내기 / 버퍼 맡기기 / 팔레트 닫기. 평균 + 나쁜 경우 + 대체 단계 진입 위험 |
| L6 실행 | 집기 도착 시 최고안. 계산이 부족하면 L4 결과로 즉시 실행 |

## 2-1. 배치도 + 버퍼 결합 (순서 바꾸는 창)
- **배치도 형태**: "칸 + 선후 관계"로 만듭니다.
  - 칸에는 SKU 종류만 배정하므로, 같은 SKU면 어느 박스든 들어갈 수 있습니다(하중 기준 충족 시).
  - 칸마다 받침이 될 아래 칸을 기록하고, 받침이 다 채워진 칸을 **준비된 칸**이라 부릅니다.
- **집기 시점 판단**:
  1. 칸이 준비됨 → 그 칸에 놓기
  2. 준비 안 됨 + 받침 박스가 대기열에 곧 보임 → 버퍼에 맡기고 대기
  3. 받침 박스가 당분간 안 올 것 같음 → 배치도 밖의 가장 좋은 자리에 놓고 배치도 재계산
  4. 버퍼가 비상칸만 남음 → 맡기지 않음(준비된 버퍼 박스부터 꺼내 공간 확보)
  5. 놓은 결과 버퍼 박스의 칸이 준비됨 → 연쇄로 꺼내 놓기
- **대기 여부 판단**: 예상 대기 시간으로 정합니다.
  - 대기열에 보이면 확정값이고, 안 보이면 미입고 수량으로 계산한 도착 확률을 씁니다.
  - L5에서 "대기 비용(버퍼 이동 + 칸 점유)"과 "이탈 비용(효율 손실 + 안정성 여유 감소)"을 비교합니다.
  - 계량 구간이 상류일수록 대기 판단이 정확해집니다.
- **안전장치**: 오래 기다린 박스는 강제로 꺼내고, 버퍼 1칸은 비상용으로 남기고, 꺼내 놓을 때도 0.3 g 하드 제약을 적용합니다.

## 3. 점수식 (낮을수록 좋음)
1. **안정성** (0.3 g는 하드 제약이고, 그 이상은 비선형으로 약하게 가산)
   - 충격 여유: 기둥 전체의 임계 가속도 − 0.3 g
   - 맞물림, 옆면 지지, 받침
2. **하중 여유** (비선형): 누적 하중 ÷ 허용치
3. **공간 효율**
   - 높이, 표면 평탄도
   - **빈틈**: 둘레 틈·못 쓰는 틈은 큰 벌점, 남은 박스로 채울 수 있는 틈은 작은 벌점
4. **배치도**: 구역 일치 비용(강하게) + 미래 박스용 구역 침범 비용(남은 부피 비례)
5. **시간**: 집기 → 놓기 거리 기반 로봇 시간, 버퍼 이동

**가중치**: 1과 2는 설계로 고정합니다. 3~5는 "현장 효율 점수"를 보상으로 CEM 학습합니다.

## 4. 안정한 자리가 없을 때 / 팔레트 교체 판단
1. 버퍼 박스 중 안정한 자리가 있는 박스를 먼저 놓기
2. 현재 박스를 버퍼에 맡기기
3. **재적재 vs 팔레트 교체를 비용으로 비교**해 더 싼 쪽을 고릅니다.
   - **교체 비용** = 교체·랩 시간 + **총적재 손실**((1 − 채움률) × 트럭 1칸 비용) + 트럭 배차 영향
   - **재적재 비용** = 이동 박스 수 × 박스당 이동 시간 + 재적재 중 안정성 위험. 옮긴 뒤 구조도 0.3 g 제약을 통과해야 하고, 실제로 자리가 생기는 경우에만 후보가 됩니다.
   - 재적재가 가능하고 더 싸면 재적재, 아니면 교체합니다. 빈 바닥은 항상 가능하므로 교체로 반드시 성공합니다.
4. 규격 이상 박스만 NG 라인 / 작업자 확인

같은 비용식을 평소의 "팔레트 닫기" 판단(계속 채우기 vs 지금 닫기)에도 씁니다.

## 5. 검증 지표
- **안정성**: 단계적 충격 시험(랩 없음). 0.3 g 통과율 **100% 목표**, 버틴 g 분포. 랩 상한 비교(둘레 가상 벽)
- **효율**: 팔레트 수, 처리량(교체·랩 포함), 트럭 대수 / N박스
- **실시간**: 결정 시간, 집기 도착 시 계산 중단 빈도, 대체 단계 발생 빈도
- **기준선 비교**: 팀 현재(DBLF + Rule), 같은 데이터·같은 제약
