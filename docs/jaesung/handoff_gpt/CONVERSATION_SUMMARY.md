## 1. 프로젝트와 역할

- 대회: HD현대로보틱스 PAC2026 Mission 1 — 혼합 박스 팔레타이징.
- 로봇: HDR50-22, **6축으로 진행**(사용자 결정). 카메라는 **일반 RGB만 사용**(깊이 카메라 불필요로 결론).
- 우리(재성) 역할: **적재 알고리즘이 정한 명령을 실제로 실행하는 쪽**(작업셀·실행기). 적재 위치·버퍼 사용·팔레트 교체 "정책"은 알고리즘(팀) 몫이며 우리는 고민하지 않음.
- 실제 흡착판 사양 없음, 실제 팔레트 치수 없음 → 임시값 유지(다시 묻지 말 것).

## 2. 사용자 선호 / 규칙 (반드시 지킬 것)

- **모든 답변·질문은 한국어**(영어 잘 못함). 코드/경로만 영어.

- 성능 수치는 실측만 보고(추측 금지).
- 진행 상황을 짧은 한국어 메시지로 알려주기를 선호.
- **이미 통과한 부분은 다시 검증하지 말고, 실패한 지점부터** 재현·수정·검증 (복원 스크립트 사용).

## 4. 대화 흐름 (시간순 요약)

1. **인수인계 확인**: V4.2 성공, V4.3(자동 계량) 포즈 수신 실패 상태에서 시작.
2. **V4.3 자동 계량 완성**: PosePublisher nested pose 수정, 브리지 고아 프로세스·Ctrl+C·tare 문제 수정 → Gazebo 3회 연속 성공. 진행 메시지(한국어 단계 표시) 추가.
3. **그리퍼(흡착판)**: DetachableJoint + Contact + TouchPlugin으로 흡착 구현(오픈 플러그인 사용).
4. **MoveIt2 연동**: 경로·충돌은 MoveIt2, OMPL 무작위성 제거(IK + Pilz PTP), 1cm 띄우기 없이 산업 방식처럼 바로 들어올리기, 다박스 적재 시 박스끼리 충돌 없는 경로.
5. **카메라 → 적재 알고리즘 → 실행 루프**: 고정 CCTV + 그리퍼 카메라, yaw 0/90만 회전. 데이터 생성기 시나리오로 실제 적재(S0001 24개: 20 적재, 4 보류).
6. **사용자 피드백**: 로봇이 느리고 컨베이어 반대쪽으로 돌아감 → PICK 위 대기 자세(READY) + 속도 상향. 작은 박스가 롤러 사이에 끼임 → 롤러 간격 0.095 m.
7. **야간 작업**: 팔레트 3D 물리모델(PyBullet + 브라우저 뷰어)에 로봇 셀 추가, Gazebo 결과를 그대로 재현(20/20). 원본 백업.
8. **시연(성공 1 + 실패 1)**: 박스 5번이 팔레트 상판 틈에 빠져 기울어지는 실패 재현 → 원인: 가제보 상판 틈 112 mm vs 브라우저 96 mm(둘 다 임시값). 두 엔진 동일 조건 비교 시 결과 일치(19.4° vs 19.7°) → 엔진 문제가 아니라 형상 차이. 사용자 결정으로 **브라우저 값(96 mm)으로 통일**.
9. **속도 개선**: 박스 위치 조회 4초→0.4초, 다음 박스를 로봇 작업 중 미리 투입·계량(파이프라인) → 박스당 95초 → 55초. 2배속(2 ms 스텝)은 정확도 저하로 폐기.
   - 파이프라인 중 발견한 Gazebo 함정: 그리퍼 DetachableJoint가 새 박스가 나타나는 순간 흡착판에 붙임 → 로봇이 움직일 때 생성하면 사고. 해결: 로봇이 정지(압착) 중일 때 다음 박스 생성. 순간이동(set_pose)한 박스는 이후 흡착이 안 됨 → 순간이동 금지.
10. **정렬 가이드 조사**: 혼합 SKU 라인은 카메라로 집는 위치 보정이 일반적 → 우리 방식(카메라 보정 + 스토퍼)으로 충분, 가이드 불필요. 비뚤게 들어오는 박스(±8 cm, ±10°) 시험 5/5 성공.
11. **실패 복구 구현**: 흡착 실패→물러나 재인식·재집기(최대 3회), 놓은 위치 어긋남→팔레트에서 다시 집어 다시 놓기, 동작 중단→경로 재생성, 이송 중 낙하·기울어짐→라인 정지(작업자). 시험: 4 cm 어긋남→1.4 mm, 흡착 실패→0.7 mm.
12. **측정값 vs 코드값 점검**: 무게(저울 센서)·박스 위치(카메라)·놓은 위치(오늘부터 카메라)는 측정값. 컨베이어 정지·흡착 확인·밀림 확인은 아직 시뮬레이터 정답값 사용(실제는 광센서/진공센서 필요).
13. **흡착 힘 조사**: 골판지 진공 −0.25~−0.4 bar, 안전계수 2 이상. 100 mm 컵≈8 kg, 150 mm≈18 kg(계산). 협동로봇용 그리퍼 10~20 kg, 산업용 면흡착 패드 30~60 kg. 결정: **정격 30 kg**, 초과 시 확장 옵션(pad_xl 45 kg / pad_fork 60 kg, 예시값).
14. **높이·버퍼·팔레트 교체**: 높이 기준 1.5 m(최대 1.6 m 허용). 자리 없는 박스는 버퍼(2칸)에 두고 다음 박스로 빈 공간 채우기, 버퍼가 차면 팔레트 교체. 로봇 도달 한계 TCP 1.95 m → 경로 위 박스만 넘어가도록 이송 높이 계산, 도달 불가 자리는 제외.
15. **노트북 성능**: RTX 미사용 발견 → PRIME offload, 다른 세션 작업 nice 15, 가제보 화면 끄기 옵션(GZ_GUI=0), 네트워크 변경 대응(IGN_IP).
16. **팀 통합**: 다른 대화창에서 팀 저장소에 통합 완료. 이후 작업은 통합 저장소에서.
17. **팔레트 구조**: 윗판이 공중에 떠 있던 문제 → 실제 블록형 팔레트(윗판→가로대→블록→바닥판)로 재설계(가제보·브라우저 동일). Bullet 16부품 제한으로 부품이 빠지던 숨은 버그도 수정.
18. **V4.6 설계(사용자 요청)**: 계량 구간을 컨베이어 맨 앞으로, 컨베이어 연장(연산 시간 확보), 카메라 2대(계량 구간 탑뷰 + 픽업존·적재존 CCTV), 그리퍼 카메라 제거, 버퍼를 픽업존 옆 로봇 쪽에 컨베이어와 평행하게. → 구현 완료, 일부 검증(아래 6절).
