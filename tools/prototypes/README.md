- **`wave/interlock_check.py`**: import하면 바로 실행되는 스크립트입니다. 다른 코드에서 import하지 마세요.
- **포함한 것**: 학습된 가중치(`tuned_*.json`), 비교에 쓴 하드마스크 설정 복사본(`perbox*.yaml`), 짝비교 통계(`paired_*.txt`)
- **포함하지 않은 것**: 데이터셋과 실험 산출물은 크기 때문에 넣지 않았습니다.
